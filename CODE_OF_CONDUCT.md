# Code of conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
It applies to the issues, pull requests, discussions and every other
place where the project is discussed.

## Reporting

Report unacceptable behavior by email to ohyes9711@gmail.com. Reports
are read only by the maintainer and kept confidential.

Use this form so that the report can be handled:

```text
Subject: [sparql-v12n] Code of conduct report

What happened:
Where (link to the issue, pull request, discussion or other place):
When (date and time, with time zone):
Who was involved (GitHub user names, if known):
Anything else that helps (screenshots, earlier reports):
Whether you want to be named in any follow-up: yes / no
```

The maintainer aims to answer within a week and decides on the
consequences following the enforcement guidelines of the Contributor
Covenant.

Security vulnerabilities are not reported here; see
[SECURITY.md](SECURITY.md).
